# Free 0DTE Benchmark Review

**Date:** 2026-09-29  
**Status:** External evidence / research input — not a strategy authorization

## Benchmark discovered

The public `vilkovgr/0dte-strategies` replication package is an unusually valuable free research source. It covers SPXW 0DTE structures and publishes analysis code, derived data panels, tables, tests, and documentation. The repository states that its Tier 1 derived panels were intended to support replication without requiring the paid raw-data sources.

The repository currently reports that its Git LFS budget is exceeded, so the large data panels cannot presently be fetched through the normal GitHub LFS path. Therefore we can inspect the methodology and published tables, but we cannot currently run the supplied panel locally from this environment.

## Important methodological finding

The package's August 2026 correction found a transaction-cost unit-scale error: the bid/ask half-spread had previously been charged at roughly 1/100 of its true size. The repository states that correcting this materially weakened the net results.

The corrected `0dte_implementable_pnl` table currently published in the repository reports, among the seven structures:

- Strangle/Straddle: net Sharpe -0.97 after bid/ask plus 0.5 bp.
- Iron Butterfly/Condor: net Sharpe -2.67.
- Risk Reversal: net Sharpe +0.10.
- Bull Call Spread: net Sharpe -1.59.
- Call Ratio Spread: net Sharpe -2.11.
- Bear Put Spread: net Sharpe -0.73.
- Put Ratio Spread: net Sharpe -0.61.

These are the repository's published corrected figures for its available panel, not results generated by our bot.

## Why this matters to our project

This is an important warning against assuming that 0DTE short premium automatically provides an attractive edge. Transaction costs and tail behavior can materially change the result.

It also supports our existing decision to require defined-risk structures, realistic cost modeling, account feasibility, and held-out validation before any 0DTE strategy can enter the combined portfolio.

## Artifact limitations

The public repository documents an additional data-integrity problem: the main option and VIX panels currently stop at 2024-05-01 even though other artifacts extend further and the README describes a longer 2016–2026 sample. Its GitHub issue documents this discrepancy.

Accordingly, we will not treat the repository's headline full-sample conditional figures as independently verified evidence. We will use the package primarily for methodology, implementation details, published corrected tables, and replication design until the underlying panels become accessible and internally consistent.

## Free-data opportunity

The package demonstrates that a useful derived 0DTE research panel can be distributed publicly without redistributing the proprietary raw exchange files. If its LFS data becomes accessible again, it becomes the first free historical dataset we should attempt to import into our own deterministic replay engine.

Before using it, we will verify:

1. actual date coverage;
2. timestamp resolution;
3. whether observations are interpolated rather than raw quotes;
4. bid/ask construction;
5. transaction-cost units;
6. no-look-ahead construction;
7. expiration/settlement conventions;
8. whether the panel is sufficient for our exact strategy definitions.

## Current 0DTE conclusion

**Do not buy data. Do not stop the project.**

We now have a free research path with three layers:

1. public corrected 0DTE benchmark research;
2. free historical EOD data for expiry-only/sensitivity studies;
3. prospective collection of real intraday option observations.

High-fidelity historical path-dependent replay remains conditional on obtaining a legitimate free intraday option dataset. Until then, path-dependent 0DTE results remain explicitly unvalidated rather than being approximated and mislabeled.
